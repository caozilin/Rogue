# 双人幸存者 / Twin Survivors

Godot 4.x + GDScript 的本地双人割草肉鸽 Demo，采用偏写实的 2.5D 视觉：斜俯视石质庭院、预渲染角色与怪物、柔和投影及按纵向位置排列的前后遮挡。无插件、无运行时网络依赖。火球使用动态湍流火焰、火星、地面暖光与热浪折射；冰霜领域使用冰纹、旋转符文、扩散寒雾、立体冰晶及飘雪。视觉动画跟随游戏模拟时间，暂停与升级选择时一起冻结。

冰霜脉冲随伤害频率变化，寒雾、冰面反光和边缘冰晶分层呈现。获得“庇护寒域”大技能后，领域出现半透明冰晶穹顶、曲面纹理和护盾血量条；受到庇护的友方显示护盾标记。挡弹时出现局部涟漪与冰屑，低血量时出现裂纹和警示血条，破盾时冰片散开并结束领域。

## 启动

- Windows：双击 `run.bat`。本目录 `.tools` 中若有便携 Godot，会优先使用它。
- 编辑：用 Godot 4.3 或更新的 4.x 标准版导入 `project.godot`，按 F5。
- 命令行：`godot --path .`。

打开后先选择职业。P1 默认法师，P2 默认突袭游侠；双方可以选择任意职业，也允许同职业。各自准备后开战，也可用鼠标点击“使用当前选择开始游戏”。支持调整窗口大小，画面按 1280×800 等比例缩放。使用 Compatibility 渲染，降低显卡要求。

启动界面可切换 **破线模式**：双方所选职业的全部小技能强化直接升至 Lv.3、所有大技能全部解锁，五项全局 Buff 均点满；战士以满被动护盾开场。主动技能仍由各自按键释放。直接从断界武王开始，击败后挑战天穹炮皇，最后挑战奶龙（保留奶蛙第二条命），总共三场 Boss。跳过小怪与小 Boss、经验升级和选卡；战间恢复、救援立即复活与每局一次全体复活继续生效。重开返回启动界面，可重新选择模式。

破线模式血量按双战士 / 法师＋战士 / 双法师分别配置：

| Boss | 双战士 | 法师＋战士 | 双法师 |
| --- | ---: | ---: | ---: |
| 断界武王 | 60,000 | 95,000 | 120,000 |
| 天穹炮皇 | 65,000 | 105,000 | 135,000 |
| 奶龙第一命 | 65,000 | 100,000 | 130,000 |
| 奶蛙第二命 | 80,000 | 125,000 | 160,000 |

数值基于满强化固定目标输出校准，并预留走位、技能落空和 Boss 机制造成的输出中断；真人对局仍可能需要继续调整。普通模式的血量与成长流程保持原设置。

## 操作

伤害跳字绘制在角色、Boss、弹丸和战斗特效上方、HUD 下方，带深色描边。字号随实际扣血增长，普通伤害约 16–44 像素，暴击/元素反应等高亮伤害最多 46 像素；持续 0.8 秒，向上漂浮并在末尾淡出。连续命中错开位置，最多保留 60 条，拥挤时优先显示新伤害；暂停和升级选择时冻结。

顶部中央、双方技能栏之间显示累计伤害榜，每 0.1 秒刷新并按伤害排序，颜色对应 P1 / P2。普攻、技能、元素反应、火区和灼烧均按敌人实际损失生命累计；护甲、后摇增伤和溢出伤害处理后再计数。数字带千位分隔，内部保留小数。选职业及升级选卡时隐藏，战斗结束保留成绩，重开归零。

点击伤害榜中的玩家可打开本局伤害来源明细，顶部可切换 P1 / P2。按伤害从高到低显示普攻、各个伤害技能、大强化衍生攻击、火区和灼烧的有效伤害、占本人总伤害的比例及条形图；未造成伤害的职业来源显示 0。元素反应、附身与 Boss 后摇增伤计入原攻击来源，雷楞塔伤害单列。查看时暂停战斗，点击关闭、面板外背景或按 ESC 返回；原先已手动暂停的战斗仍保持暂停。伤害来源统计与总伤害一起随重开归零。

## 职业与主动技能

两个职业的四个技能统一按玩家位置绑定：P1 使用 Q / E / R / 空格，P2 使用右键 / 1 / 2 / 3，数字支持小键盘，回车只用于开局准备。法师依次为火球、冰霜、附身、雷楞塔；战士依次为突进、战吼、巨大化撞击、救援。P1 战士 Q 自动索敌，P2 战士右键朝鼠标突进。所有技能按键只控制对应玩家。自动攻击共用同一种基础弹丸武器，所有全队 Buff 均可使用。同职业的初始属性一致，后续各自的技能强化形成不同 Build；重新开始会返回职业选择界面。下面列出未强化时的初始技能数值。

| 职业 | 初始生命 / 移速 / 伤害 / 攻击间隔 / 射程 | 主动技能 |
| --- | --- | --- |
| 法师（中远程） | 100 / 156.8 / 14 / 0.62 秒 / 480 | 雷楞塔 + 大火球 + 冰霜领域 + 附身 |
| 战士（中近程、突进穿敌） | 110 / 196 / 17 / 0.57 秒 / 255 | 突进斩 + 战吼 + 巨大化撞击 + 救援 |

- **大火球（Q）**：朝场上最高等级敌人释放，同级优先最近；没有敌人不消耗冷却。怪物等级按生成分钟增加，冲锋怪额外 +1，重装及远程怪 +2，精英 +4，Boss +10。火球初始半径 105.6（直径 211.2，为调整前宽度的 80%），速度 155，持续 4.5 秒，沿路径每 0.2 秒可再次命中同一敌人。初始不带击退，每段造成当前基础伤害的 45%。保留韧性和击退增伤计算逻辑，但基础击退为 0 时不触发位移及其伤害加成。独立冷却 15 秒，从释放时开始。
- **冰霜领域（E）**：以法师当前位置为中心跟随移动，半径 155，持续 5 秒；敌人移速降低 40%、攻速降低 35%，每 0.5 秒受到当前基础伤害 35% 的伤害。减攻速作用于接触攻击恢复、远程攻击的冷却/前摇/连射和 Boss 攻击；冰附着离开来源后维持 3 秒，随后恢复正常。两名法师领域的减速不重复叠加，伤害分别结算。独立冷却 15 秒，从释放时开始。
- **附身（R）**：吸附半径等于冰霜领域基础直径（155 × 2 = 310 像素），距离存活队友不超过 310 时瞬移到其头顶并附身 5 秒。法师移动键暂时失效，位置完全跟随队友，但普攻、Q、E 和原空格技能照常可用。附身期间伤害 +35%、技能及普攻范围 +25%、冷却恢复速度 +25%；法师不可独立锁定或受伤，队友照常承受伤害。宿主倒地立即在其当前位置弹出，正常到期也在宿主当前位置恢复移动，并获得 0.4 秒弹出保护。独立冷却 25 秒，从释放时开始；附身期间该冷却同样享受恢复加速。距离不足、队友倒地或已经存在附身/救援携带关系时不消耗冷却，避免互相绑定。附身期间战士救援不建立第二条携带关系，战吼、巨化和冲刺仍照常可用。
- 法师技能从开局可用，沿用全队伤害强化。个人升级强化火球、冰霜与雷塔，空格已改为召唤雷楞塔。升级和手动暂停会冻结火球、领域、雷楞塔、附身、雷环、裁决预警与冷却。

- **雷楞塔（P1 空格 / P2 3）**：原地召唤固定塔，初始持续 10 秒，能攻击全屏敌人，默认选择距离塔最近的画面内存活单位。初始每 0.8 秒电击一个目标，造成释放时法师基础伤害的 100%，继承全局伤害强化与释放时附身伤害增益；未获得大技能时为单体伤害，不受冰霜范围强化影响。开局储存 2 次，释放消耗 1 次，每 15 秒依次充能 1 次，最多储存 2 次，两次释放间隔 2 秒；第二次释放不重置已有充能进度。附身的冷却恢复加速也作用于充能。塔不跟随角色移动，施放者倒地后已召唤的塔仍按剩余时间攻击；倒地不能召唤。技能图标显示次数、下一次充能倒计时与进度条，中间数字显示释放间隔或无次数时的充能等待。塔在场内标注归属与剩余寿命；基础雷击与三个大技能在伤害来源中分别统计。个人强化应用于之后召唤的新塔。
- **突进斩**：P1 用 Q 触发，复用火球索敌规则，优先全图存活敌人中的最高等级，同等级选最近者；没有目标时不释放也不消耗冷却。P2 用鼠标右键，朝点击时鼠标方向释放，鼠标与角色位置重合时不释放。两人独立触发，在 0.18 秒内冲刺最多 230 像素，获得至少 0.28 秒无敌。沿实际路径造成基础伤害 ×3.2，每名敌人每段冲刺只命中一次，初始无击退。初始伤害带宽 144 像素，额外计入敌人半径。结束后开始 6 秒冷却；获得二段突袭后，第一次结束起 2 秒内可再次释放，P1 按 Q 重新索敌，P2 右键使用最新鼠标方向，不返回起点，两段共用冷却和去重返还额度。
- **战吼（P1 E / P2 1）**：从开局可用，持续 4 秒，全地图所有能索敌的普通怪、精英、远程怪和 Boss 优先锁定施放战士，不受距离限制，新生成敌人也生效。正在准备的攻击会重新瞄准，已发射弹丸保持原轨迹。结束或施放者倒地后恢复正常索敌；两名战士同时战吼时，最后施放者优先。独立冷却 20 秒，从释放时开始计算。
- **巨大化撞击（P1 R / P2 2）**：初始持续 4 秒，外观尺寸及碰撞半径变为 2 倍，移速额外增加职业初始移速的 100%，基础移动速度额外增加 100%（全队移速 Buff 已删除），减伤 80%。撞击初始就造成基础伤害 ×2，普通怪击退 120 像素，重装 72、冲锋 96、精英 18，Boss 免疫击退；同一敌人每 0.5 秒可再次撞击。冷却 15 秒，从释放开始计算。结束或倒地恢复正常体型、移速及受伤倍率。
- **救援（P1 空格 / P2 3）**：瞬移到队友当前位置，成功释放后自身获得 1 秒无敌；队友倒地时瞬移到尸体位置。存活队友被携带 3 秒，仅位移绑定在战士身上，无法相对移动，自动攻击、瞄准和所有技能照常可用，已有技能也不会被打断。携带期间冲刺仍能释放并造成伤害，但不能独立位移。队友自身无敌照常生效，实际受到的伤害转移给战士，按战士的减伤与无敌状态结算。结束或战士倒地后恢复独立移动。倒地队友会立刻以 50% 生命复活，但这一效果每局全队共用一次；机会用完后仍可瞬移到尸体，之后依照原有靠近 3 秒规则复活。独立冷却 20 秒，从释放时开始计算。救援会停止施放者进行中的冲刺，避免瞬移后被旧突进目标拉回；被携带的战士也能使用救援，届时切换由其携带队友，避免互相携带。
- 冲刺、战吼、巨化和救援可配合使用；P1 使用 Q / E / R / 空格，P2 使用右键 / 1 / 2 / 3，数字支持上排及右侧小键盘。双方同职业或不同职业时，按键均只操作对应玩家，不会同时触发队友技能。所有 Buff 和技能强化仍只使用鼠标左键选择，升级暂停时技能按键不会释放技能。
- P1 突进按火球规则索敌，P2 突进按鼠标方向；技能不消耗经验。倒地无法释放，已有技能会结束；复活后保留冷却。升级和 ESC 暂停时，技能持续时间、冷却与无敌时间也一起冻结，暂停期间不能释放技能。
- 技能伤害由职业基础伤害、全队伤害 Buff、附身增益及对应技能倍率计算；火/冰属性会根据附着触发 3 秒双倍伤害。法师个人强化作用于火球、冰霜和雷楞塔。

## 战士个人强化

每次团队升级，上方选一项全队 Buff，下方双方分别鼠标选一项自己的职业强化，三个窗口全选完才恢复。法师有六种小技能强化（各 3 级）、九种大技能（各一次），全部获取需要 27 次个人选择；战士有六种小强化（各 3 级）、十种大技能（各一次），全部获取需要 28 次个人选择。每第 3 次个人选择优先给出随机三选一大技能。下表倍率都是相对初始值的总档位，不逐次相乘。

| 小技能 | Lv1 | Lv2 | Lv3 |
| --- | --- | --- | --- |
| 冲刺 · 宽幅长驱 | 宽 ×1.5，距离 ×1.2 | 宽 ×2，距离 ×1.4 | 宽 ×2.5，距离 ×1.6 |
| 冲刺 · 穿阵回流 | 每敌返还 0.25s，上限 30% | 0.35s，上限 40% | 0.45s，上限 50% |
| 撞击 · 巨躯延展 | 体型 ×2.7，持续 4.5s | ×3.4，5s | ×4，5.5s |
| 撞击 · 重装动能 | 撞击伤害、击退 ×1.5 | ×2 | ×2.5 |

例如法师的重型弹头三级伤害依次为 `14×1.5=21`、`14×2=28`、`14×2.5=35`，而不是把三个倍率连续相乘。初始每轮 1 发、每颗子弹最多命中 1 个怪物、每秒恢复最大生命的 2%。生命上限和持续恢复合并为“生命恢复”，每级同时累加基础生命上限 50% 和回血率 1 个百分点；一级法师上限 150、每秒回 4.5 血，三级上限 250、每秒回 12.5 血。存活玩家选择后立即满血，倒地玩家仍需复活。

所有选卡附带对应技能或全局属性图标，下一等级及该档具体效果加粗显示；普通强化展示当前值到下一档的变化，大技能突出解锁效果。整张卡片和图标均可点击。

个人选卡按钮直接绑定对应玩家。冰霜图标显示各自的范围强化等级，领域使用玩家颜色的边界标记，并显示施放者、强化等级和实际半径，方便辨别两个法师的重叠领域。

“庇护寒域”冰霜屏障继承已有范围强化，不再将领域重置为基础半径 155。一级 / 二级 / 三级范围强化的半径分别为 232.5 / 310 / 387.5；护罩外观、挡弹、友方庇护和冰霜作用范围统一，附身的额外范围增益也生效。先选范围强化或先选屏障都可正常叠加。
