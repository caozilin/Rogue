# 双人幸存者 / Twin Survivors

Godot 4.x + GDScript 的本地双人 2D 割草肉鸽 Demo。无插件、无运行时网络依赖。带一张简单像素风图集（人物、蘑菇怪、紫色精英、经验晶体），场地由代码绘制；贴图缺失时自动回退为几何图形。

## 启动

- Windows：双击 `run.bat`。本目录 `.tools` 中若有便携 Godot，会优先使用它。
- 编辑：用 Godot 4.3 或更新的 4.x 标准版导入 `project.godot`，按 F5。
- 命令行：`godot --path .`。

打开后先选择职业。P1 默认压制射手，P2 默认折返游侠；双方可以选择任意职业，也允许同职业。各自准备后开战，也可用鼠标点击“使用当前选择开始游戏”。支持调整窗口大小，画面按 1280×800 等比例缩放。使用 Compatibility 渲染，降低显卡要求。

## 操作

| 动作 | P1（青色脚下圈、P1 标记） | P2（橙色脚下圈、P2 标记） |
| --- | --- | --- |
| 移动 | WASD | 方向键 |
| 主动技能 / 开局准备 | 空格 | 回车（支持小键盘回车） |
| 开局选职业 | 1：射手 / 2：游侠 | 7：射手 / 8：游侠，支持小键盘 |
| 自己的技能强化 | 1 / 2 / 3 | 7 / 8 / 9，也支持小键盘 |
| 全队共享 Buff（只选一项，两人受益） | 4 / 5 / 6 或鼠标 | 相同 |
| 攻击 | 自动瞄准射程内最近敌人 | 相同 |
| 复活队友 | 靠近倒地队友，在绿色圈内停留 3 秒 | 相同 |

也可以用鼠标点击各自的升级卡。ESC 暂停/继续整个游戏；两人倒地后按 R 或点击按钮重开。悬停顶部属性文字可查看详细武器属性和升级次数。

## 职业与主动技能

两种职业都只需要移动和一个技能键，自动攻击共用同一种基础弹丸武器，所有全队 Buff 均可使用。同职业的初始属性一致，后续各自的技能强化形成不同 Build；重新开始会返回职业选择界面。下面列出未强化时的初始技能数值。

| 职业 | 初始生命 / 移速 / 伤害 / 攻击间隔 / 射程 | 主动技能 |
| --- | --- | --- |
| 压制射手（中远程、易操作） | 100 / 225 / 14 / 0.62 秒 / 480 | 火力压制 |
| 折返游侠（中近程、高操作上限） | 110 / 245 / 17 / 0.57 秒 / 255 | 折返突袭 |

- **火力压制**：持续 4 秒，攻速 ×2.2、射程 ×1.35、移速 ×0.85。每轮自动射击额外向射程内另一名最近敌人发射一发子弹，伤害为当前基础伤害的 75%，继承穿透与暴击；没有第二个目标时不发射额外弹。冷却 10 秒，从持续结束后计算；未强化时两次释放至少间隔 14 秒。技能强化后的冷却同样在持续结束后开始，倒地打断技能后也进入冷却。顶部显示持续时间与冷却，角色出现金色光环。
- **折返突袭**：沿当前移动方向在 0.18 秒内突进最多 230 像素，获得至少 0.28 秒无敌并标记途经敌人；站立时沿上一次移动方向，首次默认为右。技能开始后的 1.2 秒内，再按同一个技能键立即返回原点，获得至少 0.20 秒无敌，并对所有仍存活的本玩家标记目标造成当前基础伤害 ×3.2 的额外伤害（本次固定倍率，不额外掷暴击）。返回或窗口结束后进入 6 秒冷却；不返回则停留在新位置，清除标记，不引爆。原点有进度圆环，敌人有玩家颜色的标记，两名游侠的标记彼此独立。
- 突进方向不受自动索敌方向影响；技能不消耗经验。倒地无法释放，已有技能会结束；复活后保留冷却。升级和 ESC 暂停时，技能持续时间、返回窗口、冷却与无敌时间也一起冻结，暂停期间不能释放技能。
- 技能只临时修正属性，不改变 Buff 已叠加的基础数值。伤害 Buff 同样提升引爆伤害；攻速、射程、穿透、暴击等 Buff 与射手压制效果配合。

## 三窗口升级

每次团队升级暂停战斗，同时打开三个半透明窗口。上方从原有九种 Buff 中随机三选一，选中效果立即同时作用于 P1、P2；下方左侧是 P1 的主动技能强化，右侧是 P2 的主动技能强化。三个窗口都选完才恢复。

上方按 **4 / 5 / 6** 或鼠标选，全队只选一次；左下按 **1 / 2 / 3**，右下按 **7 / 8 / 9**。三项可以按任意顺序选择，已完成的窗口显示等待状态，不能重复领取。连续跨级时每一级保留一项全队 Buff 和双方各一次技能强化；倒地玩家也可以选择。暂停期间技能计时全部冻结。

每个职业固定有三种可重复强化，顺序独立随机；只改变选择者的主动技能属性。同职业双方也可选不同路线。持续时间、射程、距离、无敌、冷却设边界；达到边界后附带的技能伤害仍能继续叠乘，避免完全无效的卡片。

| 职业 | 强化方向 | 每次效果 |
| --- | --- | --- |
| 压制射手 | 火力超频 | 压制攻速倍率 ×1.18（最多 4.4）；额外弹伤害 ×1.25 |
| 压制射手 | 持久压制 | 持续时间 ×1.16（最多 7 秒）；冷却 ×0.97（至少 8 秒）；额外弹伤害 ×1.10 |
| 压制射手 | 机动瞄准 | 压制射程倍率 ×1.16（最多 2.2）；移速修正 ×1.06（最多恢复到正常速度）；额外弹伤害 ×1.12 |
| 折返游侠 | 裂解标记 | 返程引爆伤害 ×1.35 |
| 折返游侠 | 长距折返 | 突进距离 ×1.18（最多 420）；返回窗口 ×1.12（最多 2.2 秒）；引爆伤害 ×1.10 |
| 折返游侠 | 闪避节奏 | 突进和返回无敌时间 ×1.16（最多 0.55 / 0.40 秒）；冷却 ×0.94（至少 3.8 秒）；引爆伤害 ×1.10 |

例如射手的一发额外弹最初为当前基础伤害的 75%，两次火力超频后为 `75% × 1.25² ≈ 117.2%`。全队伤害 Buff 与个人技能倍率相乘。新技能持续时间和冷却设置从下一次释放使用；正在进行的技能剩余秒数不重新计时。

## 规则

- 两人按所选职业初始化属性，共用基础武器；选择相同职业时初始属性完全相同。颜色、P1/P2 标记与小型职业饰件用于辨认玩家。
- 敌人从场地外生成，追击最近的可行动玩家，接触伤害有 0.7 秒受伤保护，避免一帧连续扣血。
- 击杀掉绿色经验晶体，两人均可拾取；任何玩家拾取都计入同一个团队经验池。共享经验与团队等级，双方不会争抢经验。拾取半径固定为 115，不再有扩大经验拾取范围的 Buff。
- 基础属性 Buff 为全队共享，同次随机三选一不会重复卡片；个人技能属性、强化次数与随机排序彼此独立。不同职业的三种技能强化内容不同。
- 升级时同时出现上方共享 Buff、左下 P1 技能、右下 P2 技能三个半透明窗口，整个战斗画面完全静止：双方移动、敌人、子弹、拾取、恢复、救援、技能计时与游戏计时均暂停，数字键和鼠标选择正常响应。
- 每次团队升级选一次全队 Buff，双方再各选一次个人技能强化。各窗口可独立立即选择，所有积累的三类选择全部完成才恢复。
- 一次跨多级时，每个窗口独立逐级选择，选完本级立即显示对应的下一级选项。倒地玩家也能选择自己的技能强化；共享生命恢复不会自动复活。
- 大量经验一次跨多级时，为每一级依次选卡，不丢升级。积累的经验与升级在倒地后保留。
- 一个基础弹丸武器，支持伤害、攻速、射弹、射程、穿透、暴击，以及生命、移速、恢复九种重复叠加升级。
- 团队升级需求为 `96 + 64 × (等级 - 1)^1.35`。共享池接收双方经验，因此门槛按原个人需求的两倍计算，保持先前降低后的升级频率；首次升级需要 96 经验（16 个初始普通敌人的掉落），升级后共选一项团队 Buff 和两项个人技能强化。
- 每次 Buff 按当前属性乘倍率重复叠加，形成指数增长；射弹和穿透保留小数容量，显示时向上取整，避免固定加一。具体倍率见下表。
- 每轮至少有一发瞄准最近敌人的中央弹丸，其余弹丸形成扇形；穿透弹不会重复伤害同一个敌人，使用线段碰撞避免高速漏判。
- 基础属性上限：攻击间隔最短 0.10 秒、射弹最多 12 发、穿透最多 8 人、射程 1200、移速 420、恢复 15/s。主动技能临时倍率可以超过基础限制，仍受子弹对象预算约束。全队 Buff 的上限工具卡只在双方都达到主属性上限时移出池；暴击率最多 100%，到顶后暴击伤害仍可继续指数叠加。伤害、生命与暴击伤害始终保留三种有效可重复选项。
- 倒地者不能行动、攻击或拾取；队友进入 66 像素半径后自动救援。离开范围进度快速衰减。复活恢复 50% 生命并获得 3 秒保护。
- 两人都倒地则结束；存活 10 分钟显示达成提示，随后可继续，无固定关卡终点。
- 难度随时间增加：生命、伤害、移动速度、生成频率增强；45 秒后加入紫色精英几何敌人。不是在 10 分钟硬性结束。
- 敌人 / 子弹 / 经验晶体分别限制为 160 / 320 / 220。经验超出数量预算时合并到附近晶体，保留经验值，避免长局无限堆积对象。

## 全队 Buff 数值

| Buff | 每次效果 |
| --- | --- |
| 重型弹头 | 伤害 ×1.45 |
| 快速供弹 | 攻速 ×1.40（间隔 ÷1.40） |
| 散射弹仓 | 射弹容量 ×1.65；实际发数 1→2→3→5→8→12 |
| 远程瞄准 | 射程 ×1.28、弹速 ×1.15、伤害 ×1.12 |
| 贯穿弹头 | 命中容量 ×1.70；额外穿透 0→1→2→4→8 |
| 精准射击 | 暴击率 ×2.50、暴击伤害 ×1.20 |
| 生命强化 | 生命上限 ×1.40、恢复新生命上限的 40% |
| 轻盈步伐 | 移速 ×1.16、攻速 ×1.08 |
| 持续恢复 | 恢复速度 ×2.50、立即恢复生命上限的 12% |

例如连续选择三次重型弹头，伤害为 `14 × 1.45³ ≈ 42.68`。各方向还能相互叠乘，数值达到上限时依照上面的上限规则处理。

## 文件结构及修改入口

```text
project.godot           项目配置、主场景、分辨率与渲染
scenes/main.tscn        唯一入口场景
scripts/balance.gd     初始属性、场地、难度曲线、对象预算、复活参数
scripts/classes.gd     两职业初始差异、主动技能数值与说明
scripts/class_select.gd 开局双人职业选择、准备与开始界面
scripts/skill_upgrades.gd 两职业各三种技能强化、叠加与边界
scripts/art.gd         共享图集切片及缺图回退
scripts/game.gd        主模拟、输入、生成、索敌、攻击、碰撞、经验与结束
scripts/player.gd      个人状态、升级队列、倒地复活、玩家绘制
scripts/upgrades.gd    共享 Buff 目录、随机三选一、双方属性叠加
scripts/enemy.gd       敌人属性及绘制
scripts/projectile.gd  弹丸属性及绘制
scripts/xp_gem.gd      经验晶体属性及绘制
scripts/hud.gd         双人状态栏、三窗口升级、暂停与结束界面
assets/sprites/        一张基础像素图集及生成说明
tests/smoke.gd         共享经验、三窗口与技能强化的最小流程检查
tests/skills.gd        职业选择与主动技能的短流程检查
tests/playability.gd   正常属性的机器人十分钟对局检查
tests/balance.gd       数值、指数叠加与上限检查
tests/capture.gd       实际渲染截图检查
run.bat                Windows 快速启动
```

没有商店、装备栏、剧情、地图切换、联机、正式美术或复杂动画。只加入基础像素角色贴图、脚下标记和轻微移动起伏。主模拟集中在 `Game.simulate()`，实体负责状态与绘制；便于改数值、添加升级或替换图片。

## 验证

后续默认只做启动和当前改动的最小检查；长局与数值专项脚本保留供需要时使用，不要求每次修改都运行。

```powershell
# 默认最小启动检查
godot --headless --path . --quit-after 120
# 新职业与技能的最小流程检查
godot --headless --path . --script res://tests/skills.gd
# 首次导入与解析
godot --headless --path . --editor --quit
# 共享经验、三窗口选择与个人技能强化的最小检查
godot --headless --path . --script res://tests/smoke.gd
# 正常生命值与属性的机器人十分钟对局
godot --headless --path . --script res://tests/playability.gd
# 数值专项检查（修改 Buff 时可按需运行）
godot --headless --path . --script res://tests/balance.gd
# 用实际窗口和 GPU 渲染生成玩法、升级、结束截图
godot --path . --script res://tests/capture.gd
# 仅截取职业选择与技能画面
godot --path . --script res://tests/capture.gd -- --classes-only
```

最小检查只验证启动与当前选择、强化流程，不运行十分钟模拟。正常属性机器人对局与数值专项检查仍可按需运行；现有长局机器人不会主动释放技能，不代表新职业数值已完成真人平衡。生成的截图和日志放在 `artifacts/`，验证记录见 `TEST_RESULTS.md`。
